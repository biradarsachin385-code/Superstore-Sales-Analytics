# Superstore Sales Analytics

## Project Overview

An end-to-end sales analytics project using SQL and Power BI to analyze sales, profit, regional performance, product categories, and business trends using the Superstore dataset.

## Objective

The objective of this project is to transform raw sales data into meaningful business insights and an interactive Power BI dashboard.

## Tools & Technologies

- Power BI
- SQL
- Power Query
- DAX
- CSV
- Git & GitHub

## Project Workflow

1. Cleaned and prepared the Superstore dataset.
2. Performed data analysis using SQL.
3. Created business metrics such as Total Sales, Total Profit, and Profit Margin.
4. Built an interactive Power BI dashboard.
5. Analyzed regional and category-level performance.
6. Organized the Power BI report as a `.pbip` project for version control.

## Key Analysis

The project includes analysis of:

- Total Sales
- Total Profit
- Profit Margin
- Regional performance
- Category performance
- Sales and profit trends
- Product-level performance
